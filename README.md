# GiggleType

**Live Demo:** [https://biswatma.github.io/giggletype/](https://biswatma.github.io/giggletype/)

## Letter & Number Game for Toddlers (AI-Powered)

An interactive learning game designed for toddlers! When your child types any letter or number on the keyboard, it pops up visually on the screen and is pronounced aloud using AI-generated speech. This simple yet engaging activity helps young children recognize letters and numbers, improves typing familiarity, and builds early language skills — all in a fun and safe environment.

✨ **Features:**

*   Instant visual pop-up of typed letters and numbers
*   Clear AI voice pronunciation for each input
*   Toddler-friendly, distraction-free interface
*   Encourages early learning through play
*   Random vibrant colors for each character
*   Fun bounce animation and balloon effects

Ideal for parents looking to introduce letters and numbers in an engaging, tech-savvy way!
